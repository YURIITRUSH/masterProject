## 1. 🚀 Загальна архітектура та наукова новизна
Комплекс реалізує трирівневу архітектуру (Hardware-in-the-Loop), що розділяє задачі жорсткого реального часу, збору даних та інтелектуальної обробки.

**Головна наукова новизна** полягає у впровадженні алгоритму **Neural Gain Scheduling** та порівнянні трьох підходів до керування:
1.  **Baseline (Ручний PID):** Класичні фіксовані коефіцієнти, зашиті в прошивку.
2.  **Hybrid (Static AI):** Нейромережа розраховує найкращі $K_p, K_i, K_d$ один раз на початку руху і фіксує їх.
3.  **Dynamic AI (Neural Gain Scheduling):** Нейромережа динамічно змінює коефіцієнти в реальному часі (кожні 100 мс) залежно від поточної похибки.

### Рівні системи:
1.  **Нижній рівень (Hard Real-Time):** Arduino. Зчитує енкодер та INA219, реалізує каскадний закон керування PID-PBC з частотою $100$ Гц.
2.  **Верхній рівень (Soft Real-Time):** Хост-ПК (Python, файл `main.py`). Єдиний CLI-інструмент для збору телеметрії, калібрування, навчання ШІ та генерації PDF-звітів.
3.  **Рівень ШІ:** Навчання нейромережі TensorFlow на даних цифрового двійника (Digital Twin) та трансляція коефіцієнтів на мікроконтролер.

## 2. 🔌 Апаратна частина

**Апаратна платформа:** Arduino UNO, драйвер L298N, мікродвигун N20 (з квадратурним енкодером), датчик струму/напруги INA219.

### 2.1. Схема з'єднань (Pinout)
*   **Керування:** Драйвер L298N (ENA — `D5` для ШІМ, IN1 — `D7`, IN2 — `D4` для напрямку).
*   **Зворотний зв'язок:** Енкодер (C1 — `D2`, C2 — `D9`, апаратні переривання).
*   **Моніторинг:** INA219 на I2C (SDA — `A4`, SCL — `A5`, адреса `0x40`). Шунт увімкнено послідовно між виходом драйвера та мотором, що дозволяє вимірювати реальну напругу безпосередньо на обмотках.
*   **Живлення:** Силова частина (L298N) — $12$ В. Логіка (Arduino, INA219) — від USB. *Земля спільна*.

### 2.2. Параметри одометрії (Критично важливо)
Під час експериментів було встановлено, що реальна кількість тіків на один оберт вихідного валу становить **2100**, а не 4200. У прошивці встановлено `TICKS_PER_REV = 2100.0f`. Застосовано time-based експоненційний фільтр швидкості ($\tau = 40$ мс).

### 2.3. Фізичні обмеження
*   **Максимальна швидкість:** Через падіння напруги на L298N та сухе тертя редуктора, максимальна досяжна швидкість становить $\approx 18.3$ рад/с.
*   **Мертва зона (Deadzone):** Рух вала починається лише при подачі ШІМ-сигналу $> 12$.
*   **Ефективна напруга:** INA219 вимірює напругу після драйвера, тому реальна напруга живлення мотора становить $V_{supply} \approx 10.4 - 11.2$ В.

## 3. 🛠️ Встановлення та налаштування (Setup)

### ⚠️ 3.0. ВАЖЛИВО: Шлях до проєкту
**Не запускайте проєкт з папок OneDrive або папок з кирилицею в назві (наприклад, `Документы`).** 
Це викликає помилку `User abort` при прошивці Arduino та проблеми з доступом Python до файлів.
Скопіюйте папку `masterProject` на диск `C:` (наприклад, `C:\HIL_Project\masterProject`) і працюйте звідти.

### 3.1. Підготовка апаратного забезпечення
1. Підключіть силову частину (L298N) до 12V, логіку (Arduino) — до USB. **Обов'язково з'єднайте GND.**
2. **Джампери на L298N:** Джампер `5V_EN` встановлено, джампер `ENA` знято.

### 3.2. Налаштування Arduino
1. Встановіть бібліотеку **`Adafruit INA219`** через Library Manager.
2. Відкрийте `arduino/projectMain/projectMain.ino`, виберіть плату Arduino UNO та натисніть **Upload**.
3. ⚠️ **УВАГА:** Після прошивки **повністю закрийте Arduino IDE**, інакше вона заблокує COM-порт.

### 3.3. Налаштування Python
1. Встановіть Python 3.13.
2. Створіть та активуйте віртуальне середовище, потім встановіть залежності:

```powershell
cd C:\HIL_Project\masterProject
python -m venv tf_env
.\tf_env\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt
```
> Файл `requirements.txt` містить: `tensorflow>=2.20.0`, `pandas`, `scipy`, `matplotlib`, `numpy`, `pyserial`, `fpdf2`, `scikit-learn`.

## 5. 🧮 Математична модель та закон керування
Реалізовано каскад: зовнішній PID-контур за швидкістю формує бажаний струм $i_{ref}$, внутрішній PBC-контур формує напругу $u$.
1.  **Зовнішній контур (PID):** Інтегральна складова має вікно $|e| < 6.0$ рад/с (anti-windup). Похідна фільтрується ($\tau = 20$ мс).
2.  **Внутрішній контур (PBC):** $u = k_e \cdot \text{target} + R \cdot i_{ref} - R_d \cdot (I - i_{ref})$.
3.  **Feedforward тертя:** Додається константа $0.3 + 0.02 \cdot |\text{target}|$.
4.  **Slew Rate Limiter:** Обмежує швидкість наростання ШІМ до $1000$ од/с.

## 6. 💻 Програмне забезпечення верхнього рівня
Єдиний CLI-контролер у `main.py` містить модулі:
*   `Config`: централізоване зберігання налаштувань.
*   `DigitalTwin`: математична модель (аналітичне рішення + Ейлер з підкроками).
*   `SerialManager`: безпечна робота з COM-портом.
*   `DataCollector`: збір даних (автоматично скидає PID до `0.4/0.1/0.002` для Baseline).
*   `HILController`: керування (Baseline / Hybrid / Dynamic AI).
*   `ReportGenerator`: створення PDF (використовує `np.trapezoid`, обрізає неактивні фази).

## 7. 🧬 Цифровий двійник та калібрування
1.  **Чисельна стійкість:** Використовується аналітичне рішення для струму та метод Ейлера з підкроками 0.5 мс для механіки.
2.  **Калібрування:** Використовується алгоритм **Non-Negative Least Squares (NNLS)**, що гарантує додатні фізичні параметри $R$ та $K_e$.

2.  **HIL-тест:** Python зчитує телеметрію та кожні 100 мс відправляє нові коефіцієнти на Arduino.

## 10. ⚠️ Troubleshooting

1. **`User abort` при прошивці Arduino:** 
   *   Переконайтеся, що шлях до папки не містить кирилиці або OneDrive. Скопіюйте проєкт на диск `C:`.
   *   Від'єднайте 12V від L298N під час прошивки.

2. **`ModuleNotFoundError: No module named 'sklearn'` або `tensorflow==2.15.0 not found`:**
   *   У вас Python 3.13. Виконайте `pip install scikit-learn` та переконайтеся, що в `requirements.txt` вказано `tensorflow>=2.20.0` (версія 2.15.0 не підтримує Python 3.13).

3. **`ValueError: I/O operation on closed file`:**
   *   Це безпечна помилка, яка виникає при завершенні програми. У коді вже додано `try...except ValueError`, тому дані зберігаються коректно.

4. **Мотор не рухається, хоча команди йдуть:**
   *   Закрийте Arduino IDE (вона блокує порт).
   *   Перевірте, чи не висіть процеси `python.exe` у Диспетчері завдань.
   *   Перевірте 12V живлення та джампер `ENA`.
