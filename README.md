## 1. 🚀 Загальна архітектура та наукова новизна
Комплекс реалізує трирівневу архітектуру (Hardware-in-the-Loop), що розділяє задачі жорсткого реального часу, збору даних та інтелектуальної обробки.

**Головна наукова новизна** полягає у впровадженні алгоритму **Neural Gain Scheduling** та порівнянні трьох підходів до керування:
1.  **Baseline (Ручний PID):** Класичні фіксовані коефіцієнти, зашиті в прошивку.
2.  **Hybrid (Static AI):** Нейромережа розраховує найкращі $K_p, K_i, K_d$ один раз на початку руху і фіксує їх.
3.  **Dynamic AI (Neural Gain Scheduling):** Нейромережа динамічно змінює коефіцієнти в реальному часі (кожні 100 мс) залежно від поточної похибки.

### Рівні системи:
1.  **Нижній рівень (Hard Real-Time):** Arduino. Зчитує енкодер та INA219, реалізує каскадний закон керування PID-PBC з частотою $100$ Гц.
2.  **Верхній рівень (Soft Real-Time):** Хост-ПК (Python, файл `main.py`). Єдиний CLI-інструмент для збору телеметрії, калібрування, навчання ШІ та генерації PDF-звітів.
3.  **Рівень ШІ:** Навчання нейромережі TensorFlow на даних цифрового двійника (Digital Twin) та трансляція коефіцієнтів на мікроконтролер.

## 2. 🔌 Апаратна частина

**Апаратна платформа:** Arduino UNO, драйвер L298N, мікродвигун N20 (з квадратурним енкодером), датчик струму/напруги INA219.

### 2.1. Схема з'єднань (Pinout)
*   **Керування:** Драйвер L298N (ENA — `D5` для ШІМ, IN1 — `D7`, IN2 — `D4` для напрямку).
*   **Зворотний зв'язок:** Енкодер (C1 — `D2`, C2 — `D9`, апаратні переривання).
*   **Моніторинг:** INA219 на I2C (SDA — `A4`, SCL — `A5`, адреса `0x40`). Шунт увімкнено послідовно між виходом драйвера та мотором, що дозволяє вимірювати реальну напругу безпосередньо на обмотках.
*   **Живлення:** Силова частина (L298N) — $12$ В. Логіка (Arduino, INA219) — від USB. *Земля спільна*.

### 2.2. Параметри одометрії (Критично важливо)
Під час експериментів було встановлено, що реальна кількість тіків на один оберт вихідного валу становить **2100**, а не 4200 (що відповідає x2 декодуванню або редуктору 1:75). У прошивці встановлено `TICKS_PER_REV = 2100.0f`. Застосовано time-based експоненційний фільтр швидкості ($\tau = 40$ мс).

### 2.3. Фізичні обмеження
*   **Максимальна швидкість:** Через падіння напруги на L298N та сухе тертя редуктора, максимальна досяжна швидкість становить $\approx 18.3$ рад/с (при 100% ШІМ).
*   **Мертва зона (Deadzone):** Рух вала починається лише при подачі ШІМ-сигналу $> 12$ (близько $0.55$ В).
*   **Ефективна напруга:** INA219 вимірює напругу після драйвера, тому реальна напруга живлення мотора становить $V_{supply} \approx 10.4 - 11.2$ В.

## 3. 🛠️ Встановлення та налаштування (Setup)

### 3.1. Підготовка апаратного забезпечення
1. Підключіть силову частину (L298N) до 12V, логіку (Arduino) — до USB. **Обов'язково з'єднайте GND.**
2. **Джампери на L298N:** Джампер `5V_EN` встановлено, джампер `ENA` знято (для зовнішнього ШІМ).

### 3.2. Налаштування Arduino
1. Встановіть бібліотеку **`Adafruit INA219`** через Library Manager в Arduino IDE.
2. Відкрийте `arduino/projectMain/projectMain.ino`, виберіть плату Arduino UNO та натисніть **Upload**.
3. ⚠️ **УВАГА:** Після прошивки **закрийте Serial Monitor**, інакше Python не зможе підключитися до COM-порту.

### 3.3. Налаштування Python
1. Встановіть Python 3.13.
2. Створіть та активуйте віртуальне середовище, потім встановіть залежності:

```powershell
python -m venv tf_env
.\tf_env\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt
```
> Файл `requirements.txt` має містити: `tensorflow`, `pandas`, `scipy`, `matplotlib`, `numpy`, `pyserial`, `fpdf2`.

## 4. 🧪 Методика проведення експериментів (Workflow)
Для доведення наукової новизни комплекс дозволяє автоматично проводити серію тестів та порівнювати три алгоритми керування.

### Крок 0: Очищення (опційно)
```powershell
Remove-Item logs\* -Force
```

### Крок 1: Збір даних (Baseline)
Виконується з фіксованими (ручними) коефіцієнтами PID:
```powershell
python main.py collect --scenario scenario.txt --tag "base_scenario"
```

### Крок 2: Калібрування та Навчання ШІ
```powershell
python main.py calibrate
python main.py train --max-target 21.0
```

### Крок 3: Тест Hybrid (Static AI)
Нейромережа підбирає коефіцієнти один раз і фіксує їх (натисніть `Ctrl+C` через 10-15 секунд):
```powershell
python main.py ai --target 15.0 --static --tag "hybrid_scenario"
```

### Крок 4: Тест Dynamic AI (Neural Gain Scheduling)
Нейромережа змінює коефіцієнти в реальному часі (натисніть `Ctrl+C` через 10-15 секунд):
```powershell
python main.py ai --target 15.0 --tag "ai_scenario"
```

> 💡 **Автоматизація:** Замість ручного запуску кроків 1-4 ви можете використати скрипт `run_all_tests.ps1`, який автоматично проганяє всі сценарії (`scenario.txt`, `scenario-stress.txt`) для всіх трьох режимів.

### Крок 5: Генерація фінального PDF-звіту
Коли всі логи зібрані, програма автоматично знайде їх, порахує метрики (IAE, перерегулювання), побудує порівняльні графіки та створить готовий PDF для диплома/звіту:
```powershell
python main.py final-report
```

## 5. 🧮 Математична модель та закон керування (Нижній рівень)
Реалізовано каскад: зовнішній PID-контур за швидкістю формує бажаний струм $i_{ref}$, внутрішній PBC-контур (Passivity-Based Control) формує напругу $u$.

1.  **Зовнішній контур (PID):** Інтегральна складова має вікно $|e| < 6.0$ рад/с (anti-windup). Похідна фільтрується ($\tau = 20$ мс).
2.  **Внутрішній контур (PBC):** 
    $$u = k_e \cdot \text{target} + R \cdot i_{ref} - R_d \cdot (I - i_{ref})$$
3.  **Feedforward тертя:** Додається константа $0.3 + 0.02 \cdot |\text{target}|$ для подолання зони нечутливості.
4.  **Slew Rate Limiter:** Обмежує швидкість наростання ШІМ до $1000$ од/с.

### Формат телеметрії (7 полів)
Дані передаються через Serial у форматі:
`Current_A, Voltage, Omega, Target, PWM, Ticks, dTicks`

## 6. 💻 Програмне забезпечення верхнього рівня
Замість багатьох розрізнених скриптів, розроблено єдиний CLI-контролер у `main.py`.

**Основні модулі:**
*   `Config` — централізоване зберігання налаштувань.
*   `DigitalTwin` — математична модель (аналітичне рішення для струму + метод Ейлера для механіки).
*   `SerialManager` — безпечна робота з COM-портом (гарантує зупинку мотора при `Ctrl+C`).
*   `DataCollector` — збір даних телеметрії.
*   `Calibrator` — ідентифікація параметрів (NNLS).
*   `AITrainer` — генерація даних (Differential Evolution) та навчання TensorFlow.
*   `HILController` — керування мотором (Baseline / Hybrid / Dynamic AI).
*   `Analyzer` — візуалізація (4-панельний графік: швидкість, ШІМ, струм, зміна $K_p, K_i, K_d$).
*   `ReportGenerator` — створення багатосторінкового PDF-звіту.

## 7. 🧬 Цифровий двійник та калібрування

### 7.1. Чисельна стійкість
Через жорсткість системи (електрична стала часу $\approx 2.4$ мс, механічна $\approx 100$ мс), стандартний `solve_ivp` (RK45) не працює. Застосовано **аналітичне рішення для струму** та **метод Ейлера з підкроками 0.5 мс** (для подолання жорсткості системи).

### 7.2. Калібрування
1.  **Напруга:** Береться реальна напруга з INA219.
2.  **Електричні параметри ($R, k_e$):** Використовується алгоритм **Non-Negative Least Squares (NNLS)**, що математично гарантує додатні фізичні параметри системи.

## 8. 🧠 Нейро-адаптивне керування
1.  **Генерація даних:** Digital Twin розв'язує задачу оптимізації для цільових швидкостей $3–21$ рад/с.
2.  **Архітектура ШІ:** Мережа типу Feedforward: `2 входи (ціль, похибка)` ➔ `Dense 32` ➔ `Dense 16` ➔ `3 виходи (Kp, Ki, Kd)`.
3.  **HIL-тест:** Python зчитує телеметрію, проганяє похибку через модель TensorFlow та кожні $100$ мс відправляє нові скориговані коефіцієнти на Arduino через послідовний порт.

## 9. 📊 Очікувані результати
*   **Ідеальний ШІ ($15.0$ рад/с):** Статична похибка $< 0.1$ рад/с.
*   **Фізичне насичення ($21.0$ рад/с):** ШІ видає $K_p=1.138$, але мотор фізично досягає лише $18.3$ рад/с через апаратні обмеження. Це яскраво демонструє подолання *Sim-to-Real Gap* (різниці між симуляцією та реальністю).
*   **PDF-звіт:** Автоматично генерує порівняльну таблицю трьох режимів (метрики IAE та перерегулювання) та накладені графіки перехідних процесів для кожного сценарію.

## 10. ⚠️ Інженерні вимоги та Troubleshooting
1.  **Механічна фіксація:** Корпус двигуна N20 має бути жорстко закріплений до основи.
2.  **Порядок увімкнення:** Спочатку підключіть USB та запустіть Python, потім подавайте $12$ В на силову частину.
3.  **Помилка `PortNotOpenError`:** Закрийте Serial Monitor у вікні Arduino IDE, оскільки порт блокується.
4.  **Мотор не рухається (напр. ціль `w 10`):** Заданий ШІМ може бути меншим за мертву зону (значення $< 12$). Перевірте живлення $12$ В.
5.  **Помилка `fpdf2`:** Виконайте команду `pip install fpdf2` у терміналі.
